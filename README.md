# Hunter Rumours
A number of helpful features for Hunter Guild Rumours.

## Rumour Tracking

This plugin tracks your current rumour, as well as the current Rumour for each hunter in the guild, making it easy to set up block lists and swap between tasks at will.

## Blocklist Helper

The sidebar includes four recommended blocklist presets and a custom builder. Custom lists are saved per active hunter, can be named and edited, and can be shared as exported JSON. The helper compares the selected list with tracked rumours and tells you which hunter to check or reroll next.
